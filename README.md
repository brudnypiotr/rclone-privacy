# Privacy policy: rclone-backup

This OAuth client (rclone-backup) is used only by its owner, Piotr Brudny, to back up
a personal project directory to his own Google Drive via rclone and restic.

- The app is not offered to other users. It is used only with the owner's Google account.
- Data accessed: files in the owner's Google Drive that rclone itself created (drive.file scope)
  and read-only access to the owner's Google Drive for a separate recording sync (drive.readonly).
- Data is not shared with third parties, sold, or used for advertising.
- Backups are encrypted client-side with restic before upload.
- Tokens are stored locally on the owner's computer in the rclone configuration file.
